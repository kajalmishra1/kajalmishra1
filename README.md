## 📌 Featured Projects

### 🏠 CampusHaven
College-focused room and PG rental platform with listings, property detail pages, roommate matching, and separate owner and renter dashboards. Mobile-first design with glassmorphism styling and minimal dependencies.
**Stack:** React · Tailwind CSS

### 🌍 UniVoice
Multilingual translation app built during my CodeAlpha AI internship. Frontend on Vercel, backend on Render.
**Stack:** React · Vite · Node.js · Express · Deep Translate API

### 🍔 OrderBuddy
Food-delivery FAQ chatbot that matches user questions to 400+ intent patterns using TF-IDF vectors and cosine similarity.
**Stack:** Python · Flask · TF-IDF · NLP

### ✅ TaskFlow
Full CRUD task management app with deployment setup (Gunicorn, WhiteNoise, Render).
**Stack:** Django
